# Dutch Learning Bot 🇳🇱

ربات تلگرام آموزش زبان هلندی برای فارسی‌زبان‌ها (سطوح CEFR A1–B2).

این مخزن در حال حاضر شامل **فاز ۱ (Foundation)** است: زیرساخت پروژه، دیتابیس،
ثبت‌نام خودکار کاربر، دستورات پایه (`/start`، `/help`، `/cancel`) و داده‌های اولیه.

## معماری

- `bot/` — هسته‌ی ربات (config، loader، main)
- `handlers/` — هندلرهای تلگرام (فقط I/O، بدون منطق تجاری)
- `services/` — منطق تجاری و یکپارچگی AI (فازهای بعد)
- `database/` — مدل‌ها، اتصال و کوئری‌ها
- `keyboards/` — کیبوردهای تلگرام
- `middlewares/` — میدل‌ورها (ثبت کاربر و ...)
- `scripts/` — اسکریپت‌های کمکی (seed و ...)

## راه‌اندازی

نیازمندی: [uv](https://docs.astral.sh/uv/) و Python 3.11–3.13.

```bash
# ۱) ساخت محیط و نصب وابستگی‌ها
uv venv --python 3.12
uv sync --extra dev

# ۲) تنظیم متغیرهای محیطی
cp .env.example .env   # سپس BOT_TOKEN و OPENAI_API_KEY را وارد کنید

# ۳) ساخت جداول دیتابیس
uv run python -c "import asyncio; from database.connection import init_db; asyncio.run(init_db())"

# ۴) پر کردن دیتابیس با داده‌ی اولیه
uv run python scripts/seed_database.py

# ۵) اجرای ربات
uv run python -m bot.main
```

سپس در تلگرام به ربات `/start` بفرستید.

## امنیت

- کلیدها فقط در `.env` (که در `.gitignore` است) — هیچ مقدار حساسی در کد نیست.
- ورودی‌های کاربر اعتبارسنجی می‌شوند و از کوئری‌های پارامتری استفاده می‌شود.
- اطلاعات حساس در لاگ‌ها نمایش داده نمی‌شود.

## نقشه‌ی راه

به `PLAN.md` مراجعه کنید. این مخزن فقط فاز ۱ را پوشش می‌دهد؛ فازهای ۲ تا ۵
(FSRS، کوییز، چت AI، تلفظ، گیمیفیکیشن، گروه‌ها، ادمین، deploy) در ادامه اضافه می‌شوند.
